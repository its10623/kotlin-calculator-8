# kotlin-calculator-precourse

## 구현할 기능 목록 정리

### 입력 구현
- [ ] 문자열을 입력 받는다.

### 기능 구현
- [ ] 입력된 문자열에 커스텀 구분자가 있는지 확인한다.
- [ ] 입력된 문자열에서 구분자와 숫자를 분리한다.
- [ ] 분리된 문자열에 커스텀 구분자가 있다면 지정을 해준다.
- [ ] 분리된 숫자의 합을 계산한다.
- [ ] 계산된 합계를 출력한다.

### 출력 구현
- [ ] 입력 안내 문구를 출력한다.
- [ ] 결과 안내 문구를 출력한다.

### 예외 처리
- [ ] 입력이 구분자와 정수가 아니면 예외 처리한다.
- [ ] 입력이 공백이면 예외 처리한다
